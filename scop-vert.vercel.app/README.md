## 📌 About The Project

**Adasa (عدسة)** is a photography-focused blog platform where users can explore photography articles, search for specific posts, filter posts by category, switch between different viewing modes, and open individual blog posts to read their full details.

The main goal of this assignment was to practice and apply **React Routing** and the concepts learned throughout the framework.

---

## ✨ Features

### 🏠 Home Page

* Clean and modern landing page.
* Photography-focused design.
* Navigation to the main sections of the website.

### 📝 Blog Page

* Display photography blog posts.
* Search for a specific blog post.
* Filter posts by category.
* Switch between **Grid View** and **List View**.
* Pagination for navigating between blog pages.

### 📖 Blog Details

* Dynamic blog details page.
* Display the complete information of the selected post.
* Navigate to the details page by selecting any blog post.

### ❌ 404 Page

* Custom error page for unavailable routes.
* Handles invalid or non-existing URLs.

### 🧭 Routing

* Multiple pages connected through **React Router**.
* Dynamic navigation between pages.
* Route-based rendering for different sections of the application.

### 📦 Local JSON Data

* Blog content is stored in a JSON file.
* The JSON data is handled as if it were a response coming from a backend.
* No external API was used in this assignment.

## ⚙️ Installation & Setup

To run the project locally:

### 1️⃣ Clone the repository

```bash
git clone https://github.com/yuossef-ashry/scop-vert.vercel.git
```

### 2️⃣ Navigate to the project directory

```bash
cd scop-vert.vercel
```

### 3️⃣ Install dependencies

```bash
npm install
```

### 4️⃣ Start the development server

```bash
npm run dev
```

The project will then be available through the local development URL provided by Vite.
